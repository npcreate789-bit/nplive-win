NP Create — ข้อตกลงการใช้งานซอฟต์แวร์ (License)
================================================

โปรดอ่านข้อตกลงต่อไปนี้ให้ครบถ้วนก่อนกด "Agree" เพื่อดำเนินการติดตั้ง.

1. กรรมสิทธิ์ในซอฟต์แวร์
   ซอฟต์แวร์ NP Create เป็นกรรมสิทธิ์ของ บริษัท เอ็นพี ครีเอ็ท จำกัด
   (NP Create Co., Ltd.) ผู้ติดตั้งได้รับเพียง "สิทธิ์ใช้งาน" ที่ระบุ
   ใน License Key ที่ได้รับเท่านั้น ไม่ได้รับโอนกรรมสิทธิ์ในซอฟต์แวร์
   หรือซอร์สโค้ดแต่อย่างใด.

2. ขอบเขตการใช้งาน
   - ใช้กับ License Key ที่ได้รับเท่านั้น
   - จำนวนเครื่องและระยะเวลาเป็นไปตามที่กำหนดใน License Key
   - ห้ามดัดแปลง, decompile, reverse engineer, หรือสร้างซอฟต์แวร์
     ลอกเลียนแบบ
   - ห้ามแชร์ License Key ให้ผู้อื่น

3. การใช้งานกับแอปของบุคคลที่สาม
   ผู้ใช้งานเป็นผู้รับผิดชอบในการปฏิบัติตามข้อตกลงการใช้งาน
   (Terms of Service) ของแอปของบุคคลที่สาม (เช่น TikTok) ที่ใช้ร่วม
   กับ NP Create. NP Create Co., Ltd. ไม่รับผิดชอบต่อการระงับ
   หรือยกเลิกบัญชีของผู้ใช้งานในแอปของบุคคลที่สามเหล่านั้น.

4. ความรับผิดจำกัด
   ซอฟต์แวร์ให้บริการ "ตามสภาพ" (AS IS) โดยไม่มีการรับประกันใดๆ
   ทั้งสิ้น. NP Create Co., Ltd. ไม่รับผิดชอบต่อความเสียหายโดยตรง
   หรือโดยอ้อมที่เกิดจากการใช้งานหรือไม่สามารถใช้งานซอฟต์แวร์ได้.

5. การยกเลิก
   หากผู้ใช้งานไม่ปฏิบัติตามข้อตกลงนี้ บริษัทมีสิทธิ์ระงับ License Key
   โดยไม่ต้องแจ้งให้ทราบล่วงหน้า และไม่ต้องคืนเงินที่ชำระไปแล้ว.

ข้อตกลงข้างต้นแล้ว.
